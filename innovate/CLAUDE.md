# Innovate: project memory

Visual research workspace for filmmakers. Product + technical spec: `../prompts/innovate-claude-code/SPEC.md`
(source of truth). Milestones are in SPEC §7; **M0–M8 are done** (scaffold, GIF Maker, boards, sharing, adapters + extension, shot lists, search, decks/reels/portfolio, agents + text-to-save).

## Commands (run from `innovate/`)

| What | Command |
|---|---|
| First-time setup | `cp .env.example .env` (set `AUTH_SECRET`), `pnpm install`, `pnpm services:up`, `pnpm db:migrate`, `pnpm fixtures` |
| Local services (Postgres+pgvector, Redis, MinIO) | `pnpm services:up` / `pnpm services:down` (= `docker compose up -d --wait`) |
| Dev (web :3000, worker, realtime ws :3001; watch mode) | `pnpm dev` |
| Typecheck / lint / unit tests | `pnpm typecheck` / `pnpm lint` / `pnpm test` |
| E2E (Playwright; builds the extension and web, starts fake sites :3199, realtime :3101, worker, `next start` :3100) | `pnpm e2e` |
| Chrome extension | `pnpm --filter @innovate/extension build` → load `apps/extension/dist` unpacked |
| Media fixtures (deterministic, generated by ffmpeg; every random filter has a fixed `seed`) | `pnpm fixtures` (`--force` to regenerate) |
| New migration after editing `packages/db/src/schema.ts` | `pnpm db:generate -- --name <what>` then `pnpm db:migrate` |
| Seed demo user, film, boards, shot list and treatment deck | `pnpm db:seed`, then with `pnpm dev` running: `pnpm --filter @innovate/worker seed:media` (sign in as `demo@innovate.local`) |
| Desktop server (whole app in one process, no Docker; data in `.data/desktop`) | `pnpm --filter @innovate/desktop build:web` then `pnpm --filter @innovate/desktop start` |
| E2E against the desktop process | `pnpm e2e:desktop` |
| Windows installer (on Windows, hoisted install) | `pnpm install --config.node-linker=hoisted`, `pnpm --filter @innovate/desktop package` → `apps/desktop/dist/` |
| Regenerate design tokens CSS | `pnpm tokens` (a unit test fails if `packages/shared/tokens.css` is stale) |

Magic links in dev are printed in the web server's terminal (and appended to `MAGIC_LINK_LOG_FILE` if set).
The MinIO console is on http://localhost:9001 (`innovate` / `innovate-secret`).

## Conventions

- **Media work only on the worker.** Web enqueues BullMQ jobs (`media` queue, job id = `media_jobs.id`)
  and polls `GET /api/jobs/:id`. The `media_jobs` row mirrors status/stage/progress/error for the UI.
- **Idempotent jobs.** Exports dedupe on `idempotency_key` (hash of the request); output keys are
  deterministic; completed jobs are returned as-is; failed jobs are retried by re-requesting.
- **Frames, not seconds.** The editor addresses integer frames on the source's rational fps grid
  (`FrameRate {num, den}`). Ranges are inclusive `[inFrame, outFrame]`; scenes are `[startFrame, endFrame)`.
  Timecodes are non-drop-frame `HH:MM:SS:FF`. Exports seek a quarter frame early, zero PTS, take N frames.
- **Exports render from the original** (or its CFR master), never the proxy. The proxy keeps every frame.
- **Variable-frame-rate sources** (phones) get a near-lossless CFR master at ingest (`packages/media/src/master.ts`,
  rate from `chooseMasterRate`); proxy, scenes and exports all use it. The untouched original is kept.
- **Ingest analysis decodes once**, in `INGEST_PARALLELISM` frame-exact chunks run in parallel
  (`analyzeSource` in `derivatives.ts`): each chunk emits proxy video, filmstrip tiles and scene stats; chunks
  overlap by one frame for scene scores, the video concatenates without re-encoding, audio is encoded once.
  Chunks need an input `-t`: `trim` alone doesn't stop the decoder.
- **Workspace scoping.** Every query filters by the session's `workspaceId` (`requireApiSession`).
- **zod on every input**; API errors are `{ error: "readable sentence" }`.
- **Design tokens** live in `packages/shared/src/tokens.ts`; use Tailwind classes generated from them
  (`bg-surface-2`, `text-text-muted`, `border-border`, `text-accent`, `timecode` utility). No raw hex in components.
- **Look and feel (decided after M8, overrides SPEC §2's dark default and the earlier beige theme):** Milanote-style.
  A neutral light theme (light-grey canvas `bg`, white cards, one blue accent; dark is the toggle), editorial serif
  (`font-serif`, Source Serif 4) for board titles and label notes. The player and filmstrip stay near-black. One slim top
  bar (`components/shell/AppShell.tsx`): menu drawer, breadcrumbs, centred title, page actions, search,
  Ask, help; pages fill it through `ShellSlot` portals ("crumbs", "title", "actions") instead of their own header rows.
  The app opens on the workspace's **Home board** (`boards.is_home`, `homeBoard()` creates it and adopts any top-level
  board as a card); new boards are cards on their parent (`createBoardOn`). Boards are free-form: anything anywhere,
  overlapping (dragging brings a card to the front), media full-bleed with title/range/source on hover, notes in white,
  yellow or label colours (white serif banners), colour swatch cards, a faint dot grid. Board chrome floats over the
  canvas (Storyflow-style): a menu bar of colourful tools on the left, zoom/fit/undo/redo + Unsorted at the top right, an
  Ask bar (opens ⌘K) at the bottom. Borrow patterns from Milanote/Storyflow, never their branding or assets.
- **Product focus (decided after M8):** Innovate is a Milanote alternative first. The menu is Home, Library, Shot
  lists, Decks (+ Agents, Settings). The GIF Maker is a board feature, not a section: the board's GIF tool opens
  `/make?board=<id>`, video cards link "Make GIF" to `/make/<id>?board=<id>`, and with `?board=` the editor saves to that
  board by default and links back to it. Reels and Portfolio still exist (routes, APIs, tests) but are out of the menu,
  and agents no longer propose reels. Don't add new top-level sections without the user asking.
- **Boards (M2):** `board_items` holds every card (reference, note, link, column, board, arrow). Columns are the
  spec's clusters: items with `columnId` stack by `position` and ignore x/y. Board cards own a child board
  (`boards.parentBoardId`). Edits go through `POST /api/boards/:id/ops` ({create, update, delete}) in debounced
  batches; the client records an inverse for each change (undo/redo, session only). Unsorted = references on no
  board. Library/boards use `serializeRefLite` (no per-item queries).
- **Sharing (M3):** share links are `share_links` rows (token, permission view|favorite|comment, scrypt password,
  expiry, revoke). A board link also opens boards nested under it (`boardInShare`), nothing else. Guests are a
  name + signed cookie. Everything that changes publishes to Redis `rt:board:<id>` (`@innovate/shared/realtime`);
  apps/realtime fans it out. Clients tag board ops with `x-client-id` to ignore their own echoes. Feedback emails
  go through `@innovate/shared/mailer` (console + MAIL_LOG_FILE in dev); daily digest = worker job scheduler.
- **Adapters (M4):** `packages/shared/src/server/adapters.ts`; off unless flagged (see docs/ADAPTERS.md). Web only
  calls `adapterFor()` to accept a link; the worker fetches. Never call real platforms in tests: e2e uses
  `apps/web/e2e/fake-sites.mjs` (fake pages + fake Vimeo API) with INGEST_ALLOW_PRIVATE_URLS=true.
- **Extension auth:** personal tokens (`api_tokens`, SHA-256 hash stored), `Authorization: Bearer inv_…` on `/api/ext/*`
  (`requireBearer`). Saves go through `lib/save.ts` (`saveFromWeb`), shared with text-to-save (M8).
- **Shot lists (M5):** `shots.position` is a float order key (`positionBetween`); "#" is free text. Motion refs are any
  reference; the PDF embeds each one's first frame (ffmpeg on the worker) and links to the live share link if one
  exists, else the app. Share links for shot lists are view-only. In e2e, wait ~100 ms after a dnd-kit drop before
  clicking (`dragTo` does): dnd-kit swallows clicks for ~50 ms after a drag.
- **Search (M6):** CLIP ViT-B/32 (quantised, transformers.js) on the worker, `embed` queue (separate from `media`, priority:
  query 1 < reference 10 < sweep 20). Rows in `embeddings` (one per image; for videos every scene thumbnail plus a frame every
  2 s, so a long shot or a missed cut is still searchable; key `(reference_id, source)`, `time` = the frame's real time), HNSW cosine index; a reference scores as its best keyframe, so video hits carry the matching
  scene's time and open the editor there. Keyword fallback = `refs_fts_idx` (hand-written in 0007, keep `refSearchDocument`
  in sync). Results are cut relative to the best similarity (CLIP cosines bunch at 0.2–0.35). Embeds are queued after
  ingest, import, export save and image upload (`queueEmbed`, never throws); a 10-minute sweep embeds anything with
  `refs.embedded_at` null. Weights download from huggingface.co on first use into MODEL_CACHE_DIR; the worker scripts set
  `NODE_USE_ENV_PROXY=1` so Node's fetch honours HTTP(S)_PROXY. Claude descriptions (`refs.auto_description`) only when
  ANTHROPIC_API_KEY is set (`apps/worker/src/claude.ts`, `claude-opus-5-5`, low effort, server-side refusal fallback).
- **Decks, reels, portfolio (M7):** documents save whole (PUT with the full slide/item list; client-made UUIDs, rows
  not in the list are deleted; last write wins, no realtime). Deck themes "paper"/"night" set `data-theme` on the slide,
  so slides use the app tokens. Share pages: deck = Presenter, reel = SharedReel (dark, clean player). The deck PDF links
  motion posters to the live share link (`#slide-N`). Reel MP4: segments share codec params so concat is `-c copy`;
  silent sources get `anullsrc`; output key = hash of the reel content. One portfolio per workspace; unpublished =
  404; slugs are global and unique (409 on clash). Videos play from the proxy (`serializePlayable().playUrl`).
- **Agents (M8, limited beta):** the loop runs on the worker (`agent` queue) on the Messages API (`claude-opus-5-5`, effort
  high, server-side refusal fallback `fallbacks: "default"`), as a manual tool loop so Cancel is checked between turns and
  every step is logged to `agent_tasks.steps`. Tools: read (library search, boards, recent uploads, scenes, Vimeo search,
  `ingest_link` which only adds to the library) and `propose_*` (create_board, add_to_board, save_links, export_clips,
  create_deck, create_reel) which only append to the proposal (`packages/shared/src/agents.ts` is the contract). The WEB
  applies an approved subset (`lib/agents.ts`), records created ids in `applied`, and undo deletes exactly those (plus
  what `ingest_link` imported). Agent exports render on the worker and are saved by `finalizeTask` when the task is read.
  Without ANTHROPIC_API_KEY the UI says agents are off. Tests use a scripted fake of the Messages API in
  `e2e/fake-sites.mjs` (ANTHROPIC_BASE_URL); SDK 1.x authenticates with `Authorization: Bearer`.
- **Text-to-save (M8):** Twilio webhook `POST /api/twilio/inbound` (SMS and WhatsApp), X-Twilio-Signature checked against
  TWILIO_WEBHOOK_URL (the exact URL Twilio calls). Verified numbers only (`phone_numbers`, scrypt-hashed 6-digit codes,
  10 min, 5 tries); links land on the workspace's "Inbox from text" board, reply is TwiML. Without Twilio credentials,
  outgoing codes go to the console + SMS_LOG_FILE (dev/e2e).
- **Desktop app (decided after M8; the user is the only user, on Windows):** same code, swapped infrastructure.
  `openQueue`/`startWorker` (`@innovate/shared/queue`) are BullMQ on servers and an in-process queue with the same
  semantics (dedupe ids, priority, delay, retries, results, schedulers) when INNOVATE_DESKTOP=1; `publish`/`cacheGet`/
  `rateLimit` use an in-process bus/map; `storageFromEnv()` returns `LocalStorage` when STORAGE_DIR is set (HMAC-signed,
  expiring `/api/files/<key>` URLs, Range support). Everything shares state through `globalThis` singletons, which is why
  web, worker and realtime must run in the one process. PGlite serialises queries: never query with the outer `db` inside a
  `db.transaction` callback (it would wait on itself). `db.execute()` results go through `rows()` (driver shapes differ).
  Jobs live in memory; at start-up the desktop server re-queues interrupted ingests/exports and fails the rest. The window
  signs in through `/api/desktop/login?token=` (per-launch token, local account `you@innovate.local`); INNOVATE_SINGLE_USER
  hides Sign out. Keep `/*turbopackIgnore: true*/` on dynamic fs paths in web code, or the standalone build traces the whole repo.
- **Ref callbacks that other components read in layout effects must be stable** (`useCallback`): an inline ref
  callback is reset to null on every render until after children's layout effects (this hid board arrows).
- **Honest gaps:** anything stubbed carries `TODO(M#)`.
- Env vars: all in `.env.example`; apps read `innovate/.env`. Never commit `.env`.
- MinIO image: `chainguard/minio` (MinIO stopped publishing community images on Docker Hub).
