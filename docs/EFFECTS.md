### PFX Camera Shake

Handheld jitter up to a violent impact shake, with rotation.

| Control | What it does |
|---|---|
| Strength | How far the frame moves. |
| Speed | How fast it shakes. |
| Rotation | How much the frame tilts. |
| Envelope | Constant shakes for the whole clip; Hit is an impact that settles. Options: Hit (fade out), Build (fade in), Pulse (peak mid-clip), Constant. |
| Motion Blur | Smears the shake. Slower to render. |
| Curve | Easing uses the two menus below; Custom opens a curve editor. |
| Ease In | Acceleration at the start. |
| Ease Out | Deceleration at the end. |

### PFX Flash Strobe

A flash that fades, or a strobe. Set the colour to black for a black flash.

| Control | What it does |
|---|---|
| Intensity | Peak strength of the flash. |
| Strobe Frames | 0 = one flash. Above 0 = frames on, then the same off. |
| Exposure Boost | Blows out the picture under the flash. |
| Envelope | Hit flashes on the first frame and fades; Constant suits a strobe. Options: Hit (fade out), Build (fade in), Pulse (peak mid-clip), Constant. |
| Flash Colour | White by default; black gives a dip to black. |
| Curve | Easing uses the two menus below; Custom opens a curve editor. |
| Ease In | Acceleration at the start. |
| Ease Out | Deceleration at the end. |
